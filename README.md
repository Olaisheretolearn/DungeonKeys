# 🎮 Dungeon Keys – Java 2D Game

A 2D top-down game written entirely in **Java with no game engine**.

You explore a dungeon, collect keys scattered across the map, and use them to open doors in search of treasure.

## 🧩 Features
- ⏱️ Timer to track progress
- 📝 Action log/messages on the left side
- 👟 Power-ups like boots to increase player speed
- 🧰 Built-in screen recording app (made separately in Java)
